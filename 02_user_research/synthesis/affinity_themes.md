# Synthesis: Thematic Pain Points

## Process

1. Copy every quote, error, wrong turn, and breakdown point from `raw_notes/P1_notes.md` through `P3_notes.md` onto its own sticky note (or spreadsheet row). Tag each one with the participant and task, for example `P2 / T2`.
2. Group notes that describe the same underlying problem. Don't start with categories; let them come from the notes.
3. Name each group with a short phrase that describes the problem from the student's point of view.
4. Keep groups backed by at least 2 participants as main themes. Single participant issues go in "Other observations."
5. Link each theme to the heuristic and WCAG findings it supports.
