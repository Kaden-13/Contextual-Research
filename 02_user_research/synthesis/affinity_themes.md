# Synthesis: Thematic Pain Points

## Process

1. Copy every quote, error, wrong turn, and breakdown point from `raw_notes/P1_notes.md` and `P2_notes.md` onto its own sticky note (or spreadsheet row). Tag each one with the participant and task, for example `P2 / T2`.
2. Group notes that describe the same underlying problem. Don't start with categories; let them come from the notes.
3. Name each group with a short phrase that describes the problem from the student's point of view.
4. Groups seen with both participants are the strongest themes. A problem seen with only one participant still counts as a theme if it was severe or the heuristic evaluation confirms it. Everything else goes in "Other observations."
5. Note where the novice (P1) and experienced user (P2) differed. Workarounds P2 uses without thinking often point to problems P1 hits head on.
6. Link each theme to the heuristic and WCAG findings it supports.
