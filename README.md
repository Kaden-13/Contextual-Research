# Weber State Registration Usability Audit (Phase 1)

**Author:** Kaden Donaldson
**Course:** Human Computer Interaction
**Target system:** Weber State University class search and registration (eWeber portal, Register for Classes app)

This repository is the documentation trail for a Phase 1 usability audit. It holds the research protocol, raw field notes, heuristic evaluation, accessibility audit, and the final report, so anyone picking this project up later can see the evidence behind each finding and recommendation.

## Repository Structure

## Method Summary

1. **Problem framing:** Defined the platform, users, core tasks, and consequences of failure.
2. **Contextual inquiry:** Observed 2 Weber State students, one new to registration and one experienced, completing 3 realistic registration tasks while thinking aloud, followed by a short semi structured interview.
3. **Synthesis:** Grouped quotes, errors, and breakdown points into themes using affinity mapping.
4. **Heuristic evaluation:** Walked through each step of the registration flow against Nielsen's 10 Usability Heuristics and rated each issue from 0 (no issue) to 4 (usability catastrophe).
5. **Accessibility audit:** Ran WAVE scans on 5 pages of the flow, then manually tested color contrast (SC 1.4.3), keyboard access and focus visibility (SC 2.4.7), and semantic structure and ARIA support.
6. **Report:** Combined all findings into an executive level report with annotated screenshots and a post mortem reflection.

## Privacy

* Participants are identified only as P1 and P2.
* No names, student IDs, grades, or other personal information are stored here.
* Sessions were not recorded. Data consists of observer notes only.
* Screenshots are taken by the researcher, not during sessions, and are cropped or blurred to remove personal details before being committed.
